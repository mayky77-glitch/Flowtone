# Установка Flowtone на Windows

## Требования

- Windows 10 или 11, 64-разрядная версия;
- не менее 8 ГБ RAM, рекомендуется 16 ГБ или больше;
- от 4 до 38 ГБ свободного места — точный объём зависит от выбранной модели;
- интернет нужен только для первой установки runtime и модели.

## Установка приложения

1. Скачайте [Flowtone-Setup-Windows-x64.exe](https://github.com/mayky77-glitch/Flowtone/releases/latest/download/Flowtone-Setup-Windows-x64.exe).
2. Запустите файл. Если SmartScreen показывает предупреждение для неподписанной сборки, проверьте, что файл скачан из официального GitHub Releases, затем выберите «Подробнее» → «Выполнить в любом случае».
3. Выберите папку установки и завершите мастер.

## Установка модели

1. Запустите Flowtone и откройте «Настроить модель».
2. Приложение покажет характеристики компьютера и отметит рекомендуемый профиль.
3. Прочитайте ссылки на официальные страницы Stable Audio, Gemma и ACE-Step, подтвердите это в окне и нажмите «Установить».
4. После загрузки модель проверяется и подключается автоматически. Терминал, Python и Hugging Face token не нужны.

Каталог разделён на компактный, сбалансированный и мощный ПК. В каждой группе есть базовый автовыбор и минимум две альтернативы; под каждой карточкой показано, чем она лучше и хуже базы. Stable Audio экономнее, ACE-Step создаёт более длинную и сложную форму, но занимает больше места и работает тяжелее. Для подходящей NVIDIA GPU автовыбор учитывает видеопамять; на остальных компьютерах используется надёжный LiteRT CPU-профиль. Рекомендация не является блокировкой: можно установить и подключить другую модель вручную.

## Удаление или смена модели

Откройте «Настроить модель» и нажмите «Удалить» у установленного профиля. Flowtone удалит только файлы выбранной модели. Если установлена другая совместимая модель, приложение сразу подключит её; иначе генерация остановится, но сохранённая музыкальная коллекция останется доступной.

Последние жанры, микс, темп, настроение, вайб, режим радио и выбранная модель сохраняются автоматически и восстанавливаются при следующем запуске.

## Восстановление старой модели

Версия 1.1.1 могла считать Stable Audio установленной, даже если в runtime отсутствовал обязательный `models\tokenizer.model`. После обновления Flowtone проверяет этот файл и совместимость пути автоматически. Если остальные компоненты сохранились, недостающий официальный tokenizer докачивается отдельно и проверяется по SHA-256. Это также обходит ошибку SentencePiece в профилях Windows с кириллическим именем пользователя.

Если автоматическое восстановление невозможно из-за отсутствия интернета, откройте «Настроить модель» и нажмите «Восстановить». Удалять папку `%APPDATA%\Flowtone`, переустанавливать системный Python или стирать музыкальную коллекцию не нужно.

## Фоновая работа

- Одновременно запускается только одна генерация.
- Количество CPU-потоков ограничивается профилем компьютера.
- При нехватке памяти активная генерация отменяется, а готовая музыка продолжает играть.
- При сворачивании окна визуальная анимация полностью останавливается. Музыка и подготовка следующего трека продолжаются без лишней перерисовки.
- Видимая анимация пластинки работает с той же целевой частотой 60 Гц, что и на macOS.

## Где хранятся данные

Музыка, runtime и модели хранятся в локальной папке данных Flowtone текущего пользователя. Удаление приложения не стирает коллекцию автоматически. Модели лучше удалять из окна Flowtone; полную коллекцию — из раздела «Моя музыка».

## Проверка загрузки

Рядом с установщиком в GitHub Release публикуется файл `Flowtone-Setup-Windows-x64.exe.sha256`. Его можно сверить в PowerShell:

```powershell
Get-FileHash .\Flowtone-Setup-Windows-x64.exe -Algorithm SHA256
```
